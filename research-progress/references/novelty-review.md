# 创新与证据分开审查

## 先拆贡献，再判差异

把营销式表述拆成原子主张。一个新名字、模块组合、应用场景和性能结果可能对应四个不同问题。
为每个 C 写出研究条件、具体变化、最近邻和可观察价值；暂缺最近邻就标“定位不足”。

识别可能的贡献类型，而不把类型直接当等级：新问题/现象、新方法、新理论/解释、新数据/测量、
系统与效率、边界/负结果、严谨复现。任务迁移和模块组合可以有贡献，但需说明新的约束或非平凡问题。
可以从问题或方法假设出发，不先验贬低方法驱动探索；推进时仍须找到可检验的问题与价值。

## 最近邻对照所需信息

- 对方和本项目解决的是同一个问题，还是仅使用相近术语？
- 两者输入/输出、数据条件、监督、假设、机制、计算和评价是否可比较？
- 新名称是否掩盖同一目标函数、近似、采样、推断或信息流？
- 差异是否改变可实现能力/知识/成本，还是参数量、训练时长、数据量或实现细节？
- 在对方合理优化后，本项目差异是否仍存在？
- 最近邻的未覆盖条件是实际限制，还是为制造区别而人为设定？

“已被覆盖”的判断也必须有定位证据；题名相似或摘要重合不足以宣判全部贡献重复。
优先权涉及公开版本与日期，不能仅按期刊年份比较，无法核实就保留争议。

## 六个维度

1. 问题重要性：真实需求、理论障碍或现有方案的明确失效；避免以热门程度代替价值。
2. 实质差异：与最接近工作在机制、假设、资源、解释或约束上的差异；查证覆盖决定判断边界。
3. 必要性：为什么必须这样做？更简单方案能否实现？增加复杂度是否解决已定位的缺口？
4. 证据可信度：研究设计能否区分竞争解释、误差和偏差？不是只看平均提升或 p 值。
5. 边界与成本：何时有效/无效、额外数据/算力/标注/硬件成本、失败代价和迁移限制。
6. 可行性：在当前资源与周期内，能否获得决定性证据？“理论上可做”不等于当前可交付。

各维用描述性判断：弱 / 有条件 / 较强 / 未知，并逐项给依据与改变判断的条件。
不把未知写成零分，不将各维求和；证据失效不能由其他维的优点抵消。
用户明确要量化时可协商维度与锚点，但必须说明是决策辅助，不是客观创新测量或录用概率。

## 主张级判定用语

- 尚无法判断：缺少必要输入或文献覆盖，不能据此说差。
- 已有工作高度覆盖：核实的已有工作已实现主要机制/能力；仍检查边界或复现价值。
- 条件或应用增量：有差异，但主要价值来自特定约束、数据、迁移或成本改进。
- 有实质差异的候选贡献：最近邻对比显示清楚的差异；其价值或机制还需验证。
- 在已核验范围内得到证据支持的贡献：差异与价值均有相称证据；保留检索和外推限制。

与“未检验 / 探索信号 / 受控支持 / 边界已检查 / 被反驳 / 相互冲突”独立记录。
候选贡献可以被反驳；一个增量工作可以有很可靠的证据。没有“顶刊级/水文级”判断。

## 反对意见压力测试

围绕主张构造最强且公平的反对解释，例如：

- 好处来自更多参数、训练预算、预训练数据或信息泄漏。
- 现象是数据划分、指标、抽样、标签或选择性报告造成的。
- “机制”只是相关可视化；消融同时改变多个变量。
- 对照调参不足，改进不超过运行/抽样变异，或成本不划算。
- 有效仅限特定条件，主张却写成一般规律。

给出能让反对解释胜出或被削弱的证据。不得把刻意弱化的替代方案当成功。
对理论研究做同样的逻辑审查：假设更强、定理包含既有特例、证明缺口、反例和可达性。

最后给一个有条件决策：继续验证 / 先修有效性缺陷 / 缩小贡献 / 转向具体新问题 / 停止当前路线 /
证据不足暂不决策，并说明最可能改变它的结果。
