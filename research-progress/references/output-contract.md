# 审查报告与可操作建议

以下是信息责任，不是强制冗长格式。小问题保留关键链条即可；完整项目分层呈现，先写决策和最重要的依据。
先提供便于扫读的判断和首要任务；详细文献卡、检索日志、逐项诊断可放附录或文件。
同一缺口只详细解释一次，其他位置引用标识，不反复重述理由。篇幅随用户要求和决策复杂度调整。
如果所在环境要求可视化、特定文件或模板，使用其呈现方式但保留这些字段。

## 1. 当前最重要的判断

一句话写明研究瓶颈与建议：继续验证 / 修正有效性缺陷 / 收窄 / 转向 / 停止当前主张 / 证据不足暂定。
随后给两三条理由、最大不确定性、改变结论的关键结果。避免空泛称赞、人格评价和录用保证。
同时点出可保留的优势与其依据，不能只罗列问题。

同时回答“这轮工作是否仍服务于研究问题”：给出主线版本、本轮实质变化、活动归类、
依据/不确定性、纠偏动作和下一检查点。短咨询可用一句话，完整项目才展开主线记录。
有界探索与基于反证的转向可以合理；不把偏离初始方法直接判为错误，也不承诺绝对不跑偏。

## 2. 材料与阶段

列实际读到的材料、版本、日期、未读/不可访问部分和事实来源类型。
对每个核心 C 分开写当前活动阶段、证据可确认的进度及依据、最早关键缺口、推进关口；
不平均成一个完成百分比。
有旧快照则对照新增证据、变化的判断和未变化的判断，不重新编号已有 C/E/P/G/T。
对问题、对象、主要评价、协议和资源的实质变化说明理由、时点与旧结论影响；
新计划不得冒充事前预测，当前记录不得冒充正式预注册。

## 3. 创新点与证据

每个 C 包含：

```text
C 标识及一句话主张：
贡献类型与条件：
当前活动阶段 / 证据可确认的进度 / 最早关键缺口：
最近邻 P 及关键相同/差异：
创新描述与理由：
证据状态、E 与出处：
六维诊断：重要性、差异、必要性、可信度、边界/成本、可行性
最强支持解释与最强竞争解释：
判断的把握及其来源/限制：
改变判断需要什么证据：
当前决策：
```

判断把握用有依据的文字描述，不凭直觉给 90% 置信度。
维度未知就明确写未知；允许可靠的增量、尚未验证但值得做的候选贡献和被否定的主张并存。

## 4. 相关论文与证据位置

按最近邻、反证/边界、补救方法说明作用；同一 P 可有多个角色，不能重复计作独立证据。
核心 P 写核实元数据、稳定链接、版本、阅读深度、原文定位、支持什么和不支持什么。
附检索日期、实际来源与查询、筛选和去重方式、限制。受限检索明确写暂定结论。
只列题名链接不算完成文献驱动的建议。

## 5. 缺口、弥补和具体修改

按严重性说明 G，区分已观察缺陷、尚未核实的风险、未报告的信息。
每条 R 连接 C/G/P/E，写机制、迁移条件、具体改动、最小区分验证、成本与风险、成功/失败/不确定分支。
提供可直接讨论的改写或步骤，而不只说“加强创新”“补充实验”“多看文献”。
没有可靠文献支持时写清楚；尚未验证的综合建议不伪装成文献定论。

## 6. 下一步任务

先给首要三项或更少的决定性任务，再列按需的后续任务。
每个 T 写：

```text
任务标识与优先级：Q0 有效性 / Q1 决策验证 / Q2 边界 / Q3 呈现
关联：C / G / R / P
要回答的问题：
与主线的直接/必要支撑/探索关联；结果会改变的决策：
执行动作与前置依赖：
主要指标、分析单位与记录方式（适用时）：
交付物与验收条件：
预先约定的阈值/停止规则及依据；无法确定时需要先做的校准：
预算档位或成本估计依据、待确认资源：
成功 / 失败 / 不确定时的下一决策：
```

执行动作为建议；已运行的任务必须另有证据。不要把制定计划写成已经完成验证。
没有资源信息时，先给能控制成本的最小路线，不承诺虚构的小时数或提升值。

## 7. 最后检查与待补信息

保留最少的、确实会改变结论的待补项。每项说明为什么需要，以及它可能改变哪个决策。
能够先做的工作继续完成，不以可选信息不足拒绝整个诊断。
如果建议停止某条路线，说明可保留的结果和转向条件；如果建议继续，说明何时应停止。
涉及实质改题或资源承诺时提出有依据的备选方向，保留旧路线，由研究者选择；
常规调整与已有授权范围内的必要工作无需反复审批。
