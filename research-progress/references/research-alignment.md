# 研究主线、偏航识别与纠偏

本流程降低无依据偏航的风险，不能保证开放式科研永远正确。偏离初始方案不自动等于跑偏：
有解释力的发现、反证和新先例可以要求改变计划。需要纠正的是目标与行动脱节、事后改写评价，
以及缺少证据却持续投入；不是所有没有立即产出正结果的工作。

## 1. 建立可修订的问题锚点

优先使用用户已写的计划与上一快照，在项目状态中记录以下字段，而不是另造一套重复文档：

- 主线版本与日期：用户明确目标、由材料推断的目标、尚待确认处分别写。
- 科学问题：研究谁/什么，在何种条件下，有什么尚不清楚的关系、限制或现象？
- 价值与缺口：理论、测量、经验、资源或使用价值；对应最近邻与已观察不足。
- 核心 C 及证据责任：什么结果支持、削弱或不能区分它？目标不是“证明自己正确”。
- 评价依据：主要结果、比较对象、分析单位、协议与适用边界；理论/定性研究采用适合的证明或分析标准。
- 当前范围与不做事项：暂不处理的任务/人群/模块及理由；与用户目标冲突时先澄清。
- 可用资源、下一关口与继续/停止条件：未知就待校准，不捏造时间、效应阈值或探索比例。

可用一句话概括：“当前要回答【问题】，在【条件】下相对【已有工作】检验【C】，
下一关口是【区分性证据】，目前不扩展到【范围】。”

早期选题可以先记录暂定问题、已知边界和一次低成本探索，逐步形成锚点。
不得因缺少正式计划、预注册或完整指标而拒绝诊断。当前才记录的计划不能伪称早于已有结果。
主线记录不等于正式预注册；若报告正式预注册，核实公开/受限记录、时间戳与实际承诺。

## 2. 每项新工作的关联检查

在提出、排序或获授权后执行一个关键任务前，回答：

1. 连接哪个研究问题、C 或 G？属于直接验证，还是可信证据所需的支撑？
2. 当前是哪种未知阻碍决策？为什么此刻做它，而不是更简单的比较、测量校准或查文献？
3. 预期哪些结果可区分解释？支持、反对、信息不足分别怎样改变下一步？
4. 使用新论文方法的条件是否成立？新颖、热门或在别人数据上提分不能独立证明本项目需要它。
5. 是否改变问题、对象、主要评价、数据/协议或资源？改变会影响哪些已有结果的可比性？
6. 最小投入、检查点和不继续的条件是什么？没有成本依据就先计时/试采样/查可获得性。

数据清理、实现验证、合理复现、测量质量和工程排错可能有必要，不能因“不直接提分”删除。
文献探索在 S0–S1 可以是主线工作；但无限阅读而不收敛到下一问题也需设本轮停止条件。
任务不必强行绑定尚未形成的正式 C；早期可以绑定明确的选题疑问，并说明它将如何帮助收敛。
本检查也约束助手建议；区分当前结论必须补的证据与可选扩展。降低主张有时优于无限追加实验。
不同项目/独立案例分别核对主线，不能从另一案例继承研究对象、分析单位或预算。

## 3. 识别具体偏航信号

### 追热点与复杂度扩张

信号：因新论文很强就加入模块，不能指出失效机制；连续添加组件却不检验最早关键缺口。
纠偏：先写问题关联与最简单替代；价值未明就做有限探索或放入候选清单，注明重新评估触发条件。
不能把“没有现成直接证据”判为想法毫无价值，但不得把设想直接升级为主线贡献。

### 代理指标或数据集替代了目标

信号：只追榜单分数，主张涉及的目标人群、场景、理论性质或资源约束逐渐消失。
纠偏：重新检查指标/基准测量了什么、未覆盖什么；补相称证据或收窄主张。
基础研究按其理论或测量目标检查对应关系，不强求业务应用；资源不足也不自动要求外部数据集。

### 看结果后移动评价标准

信号：因为某种指标好看就改主指标；依据测试结果换划分、删样本、改阈值，随后仍称原假设被确认。
纠偏：保留原协议与结果，记录变更时点/原因/受影响 C，将新分析明确为探索性；
需要确认时安排适合设计的独立证据，不能以换随机种子或重命名测试集充当独立确认。
发现标签错误、失效指标或泄漏必须修正；修正后结果单独成版并重估可比方法，不能为了“守计划”保留错误。
合理的新指标也可以有价值，只是不能借其事后选择抹去原分析或夸大证据等级。
对确认性采样/检验，记录有依据的样本终点或停止规则，不因结果刚好显著或尚不显著而任意追加。
需要序贯设计时使用相称的统计规则；探索与定性研究按其设计说明终点，不硬套固定样本量。

### 无限救火与沉没成本

信号：核心效果在公平比较后消失，仍只说“已经投入太多，再加一个模块”；预算和范围反复扩大。
纠偏：区分无效实现、低精度结果与可靠反证；按未来信息价值和剩余资源比较继续、简化、收窄、转向。
不规定“失败三次就停”或“没显著就没价值”。重复低信息实验不等于新证据，负结果本身也可以推进认识。

### 叙事偏航与硬保初始假设

信号：为了保住论文故事，把经验结果写成机制、把条件结果写成普遍规律，或隐去新文献与反证。
纠偏：回到 C/E/P 映射，降级/删除不受支持的表述；必要时修订主线并保留被否定的旧主张。
遇到重要新先例先核实覆盖范围；不能为保原创性随意改题，也不因一篇相似摘要停止整个项目。

## 4. 探索分支与合理转向

有界探索记录：问题或线索、与主线可能的关联、最小验证、资源/时间上限的依据、下一检查点、
结果不明确时怎么办、进入主线所需的新证据。没有统一的80/20比例，预算上限可因有价值信号而有理由地调整。
探索未奏效可归档；有可复查信号可升级为新假设，但须承认它来自探索，不能回写成事先预测。
偶然发现可能暂时无主线关系，可保留并限定进一步投入，不要求立即删掉，也不自动接管整个项目。

区分以下变更：

- 常规细化：实现细节、已知错误修复与已授权范围内的必要调整自主推进；影响结果时留记录。
- 协议修正：说明原缺陷、改法、时点、旧证据失效/仍适用的范围，以及重估计划。
- 范围内探索：按既有资源边界运行最小验证，不为每次正常调整新增审批。
- 实质转向：主要问题、目标对象、主要贡献或资源承诺明显变化时，给研究者可比较的选项，
  解释新路线依据、旧路线状态、可复用材料、机会成本和下一最小验证；已有明确授权则继续。

转向可以由可靠反证、新现象、新先例、目标需求或资源事实触发；困难本身不是充分依据。
不要求每次转向都先取得正结果，但需要可检查的动机与验证计划。
不能静默把“原方案失败”改写成“原目标本就如此”，也不能让锚点阻止基于证据的学习。

## 5. 何时检查、怎样汇报

在每次使用本 skill 时做与问题规模相称的核对。重点事件是：提出大改动、收到关键新结果/反证/先例、
准备扩样/扩算力、更改评价协议、进入下个关口、截止期迫近。用户要求周期复盘时随该次复盘检查；
不自动创建定时监控，也不声称看见未提供的进展。

汇报只需与当前决策有关的内容：

```text
主线版本与当前问题：
本轮相对上一版的实质变化及其依据：
活动归类：主线验证 / 必要支撑 / 有界探索 / 有依据的转向 / 偏航风险 / 暂无法判断
证据、误判可能及对哪些旧结论的影响：
现在保留、暂停、撤回、修改或需要选择的动作：
探索的预算/回流条件（如适用）：
下一检查点、所需证据和结果分支：
```

没有足够材料就写“暂无法判断”，不得默认安全；存在风险不等于已确认偏航，更不等于研究失败。
活动分类可以在不同层级并存，例如停止旧机制主张，同时开展同一问题内的有界探索；
分类用于决定动作，不强行互斥，也不将名称变化当作新证据。
短任务一句话说明关联即可，避免把主线管理变成额外研究负担。
执行时服从用户当前目标与已给授权，不以模板替代研究者选择。
