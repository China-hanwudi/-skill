# 面向决策的文献检索

目标不是凑数量，而是回答三个不同问题：已有工作覆盖多少、什么证据会推翻当前解释、哪些方法可能修复具体缺口。
普通项目诊断不自称系统综述。没有领域限制时不只搜 CNS、顶会或高被引文章。

## 1. 把主张翻译成检索概念

从每个核心 C 提取：

- 问题：任务/现象/研究对象，以及领域常用英文和中文名称。
- 机制：具体运算、学习/推断原理、数学等价形式，而不只有自创方法名。
- 条件：监督形式、数据稀缺/噪声/缺失、时序/主体/机构、硬件/延迟约束等。
- 评价：结果指标、失败模式、可识别性、可靠性、成本或理论界。

先用问题＋机制做广义检索，再加入条件收窄。分别去掉任务词和方法词，避免漏掉邻域先例。
例：某情感模型用置信度抑制坏模态，可检索 uncertainty-aware fusion、reliability weighting、
mixture-of-experts gating、missing modality、shortcut learning；这些只是概念示例，不是已检索论文。
不要把尚未公开的原文、敏感数据、受试者标识或完整内部方案提交给搜索服务；用通用概念检索。

## 2. 三路检索与来源选择

先发现可用工具；连接器可用时优先使用其结构化元数据和全文能力，没有时用网页检索官方来源。
工具名、访问权和付费资源不写死。不声称已查过无法访问的数据库。

- 最近邻路：相同问题＋机制，机制别名/等价公式，基础工作＋近期进展；检查作者自己的对比文献。
- 反证路：强简单基线、失败/负结果、方法局限、替代解释、泄漏/评估偏差；不能只查支持自己的词。
- 补救路：由 G 的失效机制生成检索词，如 grouped evaluation、calibration under shift、
  sensitivity analysis；“性能差”本身还不足以确定修复方法。

按领域尽可能使用互补发现渠道，例如学科索引/平台与引文网络。若只有一个网页搜索入口，
如实说明，再回到不同原始平台核实；访问 arXiv 和会议页面不等于已经使用两个独立学术索引，
同一研究的两个页面也不构成独立证据。可选原始平台包括：

- 计算机/AI：会议官方论文库、PMLR、OpenReview、arXiv，以及出版商记录。
- 生物医学：PubMed/PMC、期刊原文、领域报告规范；不要用预印本替代临床证据层级。
- 其他领域：相应学科索引和期刊/机构原始记录；中文问题按需补充中文索引。
- Crossref 等用于核对元数据，不把它当所有领域的全文检索替代品。

综述可帮助找术语与原文；关键新颖性和修复机制回到原始论文核实。
对最近邻做前向/后向引文追踪；访问不到的引用链如实列出。
近期时间窗按问题发展速度解释，保留无时间限制的经典与同机制搜索；不能仅查最近两年就判断首次。

## 3. 核实与阅读深度

每个影响判断的 P 记录：

- 题名、作者、年份、发表状态/版本；稳定 DOI、arXiv、会议或出版商链接。
- 从哪里发现、从哪里核实；关键元数据不一致时查第二来源，暂不能解决则标冲突。
- 阅读深度：仅记录/题名、摘要、方法与实验相关片段、全文。精读应按实际访问部分填写。
- 获取全文网页或 PDF 只表示取得载体，不等于全部精读；明确写实际读取的相关部分。
- 关键证据位置：节标题、页码、图/表/公式编号或可定位段落。
- 核心结果及条件、作者承认的限制、与 C/G 的关系及可迁移条件。

不得编 DOI、页码、引文量、作者结论、实验值或实现细节。二手文章不充当原文已验证。
只有摘要时可以报告研究方向和摘要明确的信息；具体算法迁移、精细差异或完整覆盖判断标待全文核实。
遇到更正、撤稿或版本冲突时说明证据状态，区分原结论与更新；不要依据过时版本给确定性建议。

按 DOI 去重，再按 arXiv/正式版关联和题名作者辅助去重。保留影响结论的版本差异。
不要把一个研究的多个版本当多项独立支持，也不要把综述转引重复计为独立证据。

## 4. 组织最近邻与可迁移证据

对每个 C 选择真正影响判定的最近邻，而不是相似词最多的论文。可按匹配程度描述：

- 同问题、同核心机制、条件可比：直接影响贡献覆盖判断。
- 同机制、不同领域或约束：先例与迁移候选，需说明新条件为何非平凡。
- 同问题、不同机制：强对照和竞争解释。
- 仅背景相关：用于背景，不冒充最近邻或修复证据。

对修复论文明确区分：论文直接支持 / 有条件迁移 / 根据多篇工作综合提出。
评价效果时给原研究条件和不确定性，不把论文中某数据集的提升写成当前项目预期提升。
读到支持自己与不支持自己的证据都登记，不能因方向不利而排除。

## 5. 搜索预算与停止

先围绕决定去留的核心 C/G 深读，而不是强求每类固定篇数。
完整审查通常需要若干核心原文，但数量不是合格标准。用户限制时间时，缩小问题范围并交付暂定结论。
可在最近邻稳定、关键反对解释被检查、补救候选已有适用条件且进一步检索边际收益下降时结束本轮；
记录停止原因与未覆盖数据库/语言/全文。绝不将“搜索饱和”称为新颖性的证明。

每轮日志包含：

```text
检索日期与时区：实际日期，不复用 skill 编写日
目标：C / G 与决策问题
来源与平台：实际调用成功的来源
完整查询及过滤：逐条记录；计划未执行另列
结果处理：纳入/排除的关键理由，去重及版本处理
引文追踪：以哪些 P 为起点，实际方向和覆盖
查阅深度：核心论文分别说明
限制与停止原因：无法访问的全文、未覆盖方向和预算
对判断的影响：哪些 C/G 改变，哪些仍未知
```

联网/连接器失败时，保留失败来源与错误概况，尝试可用替代来源；不无限重试。
全部失败时给内部诊断、可执行查询与核验清单，将新颖性及论文修复结论标为待检索。
